# 📘 Programação Web - Atividades

Este repositório contém as atividades desenvolvidas ao longo da disciplina de **Programação Web**, com foco no aprendizado prático e na aplicação dos principais conceitos do desenvolvimento web moderno.

## 📂 Estrutura do Repositório

As atividades estão organizadas em pastas correspondentes aos conteúdos abordados em aula, facilitando a navegação e o acompanhamento do progresso.

## 📚 Conteúdos Abordados

- ✅ HTML5: estruturação semântica de páginas
- ✅ CSS3: estilização, layouts e responsividade
- ✅ JavaScript: lógica, interatividade e manipulação do DOM
- ✅ Introdução a frameworks e bibliotecas (ex: Bootstrap, React)
- ✅ Projetos práticos integrando os conhecimentos adquiridos

## 🧑‍🎓 Objetivos da Disciplina

- Compreender os fundamentos do desenvolvimento web
- Aplicar boas práticas de codificação e organização
- Desenvolver páginas e aplicações web responsivas e interativas
- Estimular o aprendizado através da prática

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap *(opcional)*
- Git e GitHub
